Spark CPU Profile Cleaner

Remove identifiable idle/blocking samples from an existing Spark execution profile and export a CPU-focused .sparkprofile for Spark Viewer.

This page is only a profile cleaner; it does not perform plugin/MSPT attribution. It preserves the original profile duration and removes identifiable exclusive idle/blocking samples across all threads. Because Spark does not retain the original JVM thread state per aggregated sample, this is a CPU-oriented post-processing approximation rather than Spark's capture-time --ignore-sleeping.
